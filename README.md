# Grid-Mukt-Pay

Welcome to the **Grid-Mukt-Pay** project.

This project is a remix of **TokenSync Pay**, redesigned for seamless off-grid and cloud-based payment solutions using NFC and Bluetooth.

## Features
- **P2P Payments**: Send and receive tokens using Bluetooth and NFC.
- **Cloud QR**: Generate and scan QR codes for online payments.
- **Off-Grid Reliability**: Perform transfers even without an active internet connection.

## Development
To start the development server, run:
```bash
npm run dev
```
